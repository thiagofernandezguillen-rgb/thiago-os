Install Thiago OS

Works on Android TV and Google TV with Android 7.0 or newer. Takes about 5 minutes. Everything can be undone.

💻 Method A — Windows PC (one-line installer)

The installer downloads Google's official adb tool and the latest Thiago OS, connects to your TV over Wi-Fi, installs the app and helps you set it as home screen. Your PC and TV must be on the same Wi-Fi/network.

  1. Turn on developer mode on your TV: Settings → Device Preferences → About → click Build 7 times.
    (Google TV: Settings → System → About → Android TV OS build.)
  2. Turn on USB debugging: Settings → Device Preferences → Developer options → USB debugging = on. (Some TVs also have "Network debugging" — turn that on too.)
  3. Find your TV's IP address: Settings → Network & Internet → your network (looks like 192.168.1.50).
  4. On your PC: press Start, type PowerShell, open it, paste this line and press Enter: 
    irm https://thiagofernandezguillen-rgb.github.io/thiago-os/install.ps1 | iex
  5. Choose 1, type your TV's IP address. On the TV, choose "Always allow from this computer" → OK.
  6. When the Home app screen appears on your TV, select Thiago OS. If the Home button still opens the old launcher, the installer asks whether it may disable it — answer y. Done! 🎉
Is this safe? The script is short and readable: view install.ps1. It never uninstalls anything from your TV and only disables the old launcher if you say yes. Run it again and choose 2 to undo everything.

📺 Method B — TV only, with the Downloader app

  1. On your TV open the Google Play Store, search for Downloader (by AFTVnews) and install it.
  2. Allow it to install apps: Settings → Apps → Security & restrictions → Unknown sources → turn on Downloader. (Google TV: Settings → Apps → Security & Restrictions → Unknown sources.)
  3. Open Downloader and type this address: 
    thiagofernandezguillen-rgb.github.io/thiago-os/ThiagoOS.apk
  4. Press Go → Install → Done. Then continue with step 2.

📱 Method C — from your Android phone

  1. Install Send Files to TV on your phone and on your TV (both from the Play Store).
  2. On your phone, download ThiagoOS.apk.
  3. Open Send Files to TV on both devices: Receive on the TV, Send on the phone → pick ThiagoOS.apk.
  4. On the TV, open the received file and choose Install (allow "unknown sources" for Send Files to TV if asked). Continue with step 2.

💾 Method D — USB stick

  1. Download ThiagoOS.apk on your computer and copy it to a USB stick.
  2. Plug the stick into the TV. Open a file manager on the TV (for example File Commander or X-plore from the Play Store, or the TV's own media player).
  3. Select ThiagoOS.apk → Install (allow "unknown sources" for the file manager if asked). Continue with step 2.

2. Make Thiago OS your home screen

  1. Open Settings → Apps → Default apps → Home app (on some TVs: Settings → Apps → Special app access → Home app) and choose Thiago OS.
  2. Press Home on your remote. If Thiago OS opens: you're done! 🎉

The Home button still opens the old screen? On many Android TV and Google TV devices the stock launcher has a built-in higher priority and ignores your choice. The only fix is to disable (not uninstall) the stock launcher — fully reversible. Easiest: use Method A, it does this for you after asking. Manually, with adb from a PC:

adb connect <TV-IP>:5555
# Android TV:
adb shell pm disable-user --user 0 com.google.android.tvlauncher
adb shell pm disable-user --user 0 com.google.android.tvrecommendations
# Google TV (instead of tvlauncher):
adb shell pm disable-user --user 0 com.google.android.apps.tv.launcherx

Undo any time: replace disable-user --user 0 with enable. Never uninstall system apps.

Even without this step you can always open Thiago OS from your TV's apps list.

Updating

Install the newest ThiagoOS.apk the same way you installed it the first time (or run the Windows installer again and choose 1). Your favourites and app order are kept.

Uninstall / go back

  • Windows: run the one-line installer again and choose 2 — it re-enables the old launcher and removes Thiago OS.
  • On the TV: if you disabled the old launcher, first re-enable it (Settings → Apps → See all apps → Show system apps → Android TV Home / Google TV Home → Enable). Then Settings → Apps → Thiago OS → Uninstall.
  • adb: adb shell pm enable com.google.android.tvlauncher then adb uninstall be.nova.os.

Troubleshooting

"Install blocked" or nothing happens when I open the APK

Allow installing unknown apps for the app you're using (Downloader, file manager, Send Files to TV): Settings → Apps → Security & restrictions → Unknown sources.

The installer can't connect to my TV
  • PC and TV must be on the same network (not a guest network).
  • USB debugging must be on; if your TV has "Network debugging" or "ADB over network", turn that on too.
  • Check the IP address again — it can change after a restart.
  • Look at the TV: you must press OK / Always allow on the debugging prompt.
I see a blank or "loading" screen after pressing Home

Wait a few seconds — the first start after installing takes a bit longer. If it persists, re-enable the old launcher (see Uninstall) and open an issue with your TV brand and model.

The interface is in Dutch

Yes — version 1.0 is Dutch only. English and more languages are planned; translations are welcome on GitHub.

Still stuck? Open an issue on GitHub and mention your TV brand, model and Android version.
