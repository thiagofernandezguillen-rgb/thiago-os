Install in minutes.

  1. Download the latest ThiagoOS-x.y.apk from Releases.
  2. Install it with adb install ThiagoOS-x.y.apk, or with the Downloader app on your TV.
  3. Set it as default: Settings → Apps → Default apps → Home app → Thiago OS.
  4. Home button still opens the old launcher? Disable it (reversible): 
    adb shell pm disable-user --user 0 com.google.android.tvlauncher
# undo:
adb shell pm enable com.google.android.tvlauncher

Requires Android 7.0+. The interface is currently in Dutch — translations are welcome. Disabling system apps is at your own risk; never uninstall them.
